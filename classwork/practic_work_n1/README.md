# Практическая работа №1: Модули, пакеты и стандартная библиотека Python

Репозиторий содержит комплексное выполнение практической работы по изучению встроенных возможностей языка Python, управлению зависимостями и созданию устанавливаемых пакетов.

## Структура проекта
* **Разделы 1–3 (Базовые модули и пакеты):**
  * `task_1_1.py` — Знакомство со стандартными путями поиска модулей и `sys.path`.
  * `mymodule.py` / `task_1_2.py` — Создание и кастомный импорт собственного изолированного модуля.
  * `geometry/` — Собственный пакет для работы с геометрическими фигурами, содержащий подпакеты `flat`, `solid` и аналитический модуль `analytic/`.
  * `task_2_1.py` / `task_2_2.py` — Работа с псевдослучайными числами, генерация выборок и распределение игрового лута (модуль `random`).

* **Разделы 4–5 (Окружение и зависимости):**
  * `requirements.txt` — Манифест внешних зависимостей проекта для пакетного менеджера `pip`.

* **Разделы 7–8 (Комплексный проект «АРЕС-1»):**
  * `ares1/` — Каталог устанавливаемого пакета космической миссии.
  * `ares1/pyproject.toml` — Современный конфигурационный файл сборки дистрибутива по стандарту PEP 518 / PEP 621.
  * `ares1/run_mission.py` — Главный исполняемый скрипт, координирующий сбор телеметрии с использованием синусоидальной физики орбиты (`math`) и планировщика событий (`sched`).

## Инструкция по запуску телеметрии
1. Перейдите в каталог проекта:
   ```bash
   cd ares1
   ```
2. Запустите симуляцию космической миссии:
   ```bash
   python run_mission.py
   ```
